# daftar CRM — grid-template-areas darsi

Oddiy CRM bosh sahifasi: sidebar, header, main va footer `grid-template-areas` bilan joylashtirilgan.

## Ishga tushirish

`index.html` faylini brauzerda oching.

## Nimalar o'rganiladi

- `display: grid` va `grid-template-areas` bilan sahifa xaritasi
- Grid ichida grid (dashboard kartalari)
- `:root` dagi rang o'zgaruvchilari
- Font Awesome ikonkalari
- `@media` bilan responsive — faqat xaritani o'zgartirib

`style.css` dagi `QADAM 2 … QADAM 13` izohlari dars qadamlariga mos keladi.
